# Nurserik Studio Hook — как установить

Скилл из обучения **Нұрсерік** (курс PROXIMA «Монтаж с Claude», модуль 11 «Кейс: таргет-креативы»).
Нұрсеріктің оқуындағы скилл — Нұрсерік өз таргет-креативтерін осымен монтаждады.

## Установка (1 минута)
1. Распакуй архив.
2. Папку `nurserik-studio-hook` положи в `C:\Users\<твоё имя>\.claude\skills\` (на Mac: `~/.claude/skills/`).
3. Перезапусти Claude и напиши: «Смонтируй это видео скиллом Nurserik Studio Hook».

При первом запуске Claude сам поставит нужные программы (Node.js, ffmpeg, Python-пакеты) — просто разрешай.

## Орнату (қазақша)
1. Архивті аш.
2. `nurserik-studio-hook` папкасын `C:\Users\<атың>\.claude\skills\` ішіне сал.
3. Claude-ты қайта қос та, жаз: «Осы видеоны Nurserik Studio Hook скиллімен монтажда».
