# Чистый премиум

Ролик без лица 9:16 кодом: человек даёт текст (или готовую озвучку) → ты собираешь сцены в HTML → рендер в mp4 с голосом и звуками.

Пользователь, скорее всего, не программист. Объясняй простыми словами, код не показывай без просьбы. После каждого этапа: коротко «что сделал» и «что проверить».

## Первый запуск (один раз на компьютер)
1. Скопируй папку `template/` из скилла в папку проекта пользователя (например `my-premium/`).
2. Нужны Node.js 20+, ffmpeg и Google Chrome (кадры рисуются в нём). Если чего-то нет — поставь (на Mac через Homebrew, Chrome с google.com/chrome), спрашивая разрешения.
3. В проекте: `npm install`.
4. Время слов: если голос делается через ElevenLabs API (шаг 2а) — больше ничего не нужно. Иначе нужен распознаватель: Python 3.10–3.12, виртуальное окружение `.venv` с `sherpa-onnx numpy`, модель `sherpa-onnx-zipformer-ru-2024-09-18` в `models/` (GitHub k2-fsa/sherpa-onnx → releases → asr-models).

## Как собрать ролик
1. **Текст.** Попроси текст или тему. Если пишешь сам: 30–50 секунд (70–120 слов), короткие фразы по 3–7 слов, одна мысль на фразу, без ИИ-штампов. Покажи текст и дождись «ок».
2. **Голос** → `media/voice.mp3` и `media/words.json` (`[["слово", секунда], ...]`).
   - а) Есть ключ ElevenLabs в `.env` (`ELEVENLABS_API_KEY=...`): `node scripts/voice.mjs текст.txt VOICE_ID`. Ключ никогда не печатай в чат.
   - б) Есть готовый mp3 (свой голос, ElevenLabs с сайта, подключённый коннектор): положи в `media/voice.mp3`, затем `.venv/bin/python scripts/words.py media/voice.mp3 > media/words.json`. Распознавание путает имена и английские слова — сверь по тексту.
3. **План сцен.** Одна сцена = одна фраза, 1.3–4 секунды. Для каждой: текст сверху (строка 1 | строка 2), главный предмет в центре, фон, 1–3 иконки. Покажи таблицей «секунда → текст → что в кадре» и дождись «ок».
4. **Код.** Пиши сцены в `video.html` (там пример, замени его). Подключены `style.css` и `engine.js` — их не меняй без нужды, новые элементы добавляй в `style.css`.
5. **Кадры.** `node render.mjs stills 1 4.5 9 ...` — по кадру из середины каждой сцены, смотри `frames/still_*.jpg` сам. Ищи: обрезки, наложения, текст на предметах, пустые сцены. Исправь, потом покажи пользователю 3–4 кадра.
6. **Рендер.** `node render.mjs full` → `out/video.mp4` (голос + звуки + музыка из `media/music.mp3`, если есть; громкость под Reels). Минута ролика ≈ 2 минуты рендера. Для быстрой проверки начала: `node render.mjs full 10`.

## Как устроен video.html
```html
<section class="scene" data-s="6.5" data-e="10.45" data-bg="sky" data-m="230,1420,190">
  <div class="cap" data-w="0.1 0.5 | 0.94 1.1 1.5 1.74">Теперь смотри. | ты пишешь мне текст</div>
  <div class="phone" data-in="0" data-from="bottom" style="left:325px;top:640px">…</div>
  <img class="ico" src="a/icons/rocket.png" data-in="2.3" data-pop data-float="12" data-sfx="pop" style="left:790px;top:1000px">
</section>
<img id="mascot" src="a/mascot.svg">
<script src="engine.js"></script>
```
- `data-s` / `data-e` — начало и конец сцены в секундах ролика (по `words.json`). Сцены идут встык; переход (размытие + наезд) движок делает сам.
- **Все остальные времена — от начала сцены** (секунда слова минус `data-s`).
- `.cap` — текст сверху. `|` делит на две строки: первая тонкая, вторая жирная цветом акцента. `data-w` — время каждого слова по порядку (`|` в списке можно ставить для наглядности). Варианты: `cap big` (огромный заголовок), `cap low` (внизу), свой `style="top:..px"`.
- Появление любого элемента: `data-in="сек"`, `data-from="left|right|bottom|top"`, `data-pop` (пружинка), `data-dur`, `data-dist`. Исчезновение: `data-out="сек"`. Покачивание: `data-float="14"`. Медленный дрейф: `data-drift="dx,dy"`.
- Звук на появлении: `data-sfx="pop|whoosh|click|ding|thud"`, громкость `data-vol` (по умолчанию 0.13). На смене сцены whoosh ставится сам (`data-sfx="none"` на сцене — без него).
- Талисман: `data-m="x,y,размер"` на сцене — он сам перелетает между точками. Нет `data-m` — талисман скрыт. `data-cam="out"` — камера отъезжает, а не наезжает.

## Элементы (style.css)
| Элемент | Что это | Когда |
|---|---|---|
| `.cap` | Текст сверху по словам | Каждая сцена |
| `.phone` + `.screen` | Телефон; внутри `.chat`, `.msg.me`/`.msg.bot`, `.typing`, `.notif`, `.btn`, картинка | Интерфейсы, переписка, приложения. `.phone.black` — тёмный |
| `.laptop` + `.screen` | Ноутбук | Сайты, монтаж, работа за компьютером |
| `.shot` | Скрин с тенью и рамкой | Реальные скрины пользователя |
| `.glass` | Стеклянная карточка с текстом | Сводки, цифры, итоги |
| `.tile` | Плитка: иконка + подпись | Перечисления (3 шт. в ряд) |
| `.pill` (`.dark`, `.acc`) | Капсула-тег | Названия сервисов, ключевые слова |
| `.ico` | 3D-иконка из `a/icons/` | 1–3 на сцену, вокруг главного предмета |
| `.ring` (`.white`) | Кольцо рисуется вокруг цели. `left/top` = центр | Показать, куда смотреть |
| `.num` + `data-count` | Большая тонкая цифра со счётчиком | Цифры, проценты, версии |
| `.wave` | Звуковая волна, `data-play` — когда «заиграет» | Голос, музыка, озвучка |
| `.frame` | Мини-кадр 9:16 внутри кадра | Показать пример ролика/стиля |
| `.glow` (`--c:цвет`) | Цветное пятно света | Пустые светлые сцены |
| `[data-type]` | Текст печатается, `data-tin`, `data-tdur` | Сообщение в чате, промпт |

Фоны `data-bg`: светлые `mist blush sky sunset mint`, тёмные `night ink`, яркие `berry lime honey grape`. Фото: `data-img="media/фон.jpg"` (размоется само) — интерьер, небо, улица из своих фото.
Темы: класс на `<body>` для всего ролика или на `<section>` для одной сцены: без класса — светлая, `dark`, `vivid` (капс, вторая строка в белой капсуле, цвет капсулы `style="--hl:#..."`).
Иконки в `a/icons/` — Microsoft Fluent Emoji 3D (MIT). Нужна другая — скачай с github.com/microsoft/fluentui-emoji (`assets/<Name>/3D/<name>_3d.png`).

## Правила стиля (соблюдать всегда)
- **Всё строго под голос.** Слово на экране появляется, когда оно звучит. Предмет — на слове, которое его называет.
- **Одна мысль — один главный предмет** в центре. Не больше 3 иконок рядом. Много воздуха.
- **Текст:** строка 1 — 2–5 слов, строка 2 — акцент 1–4 слова. Без точек в конце строки 2. Шрифт один (Inter), начертания разные.
- **Безопасные зоны Reels:** ничего важного выше 220 px и ниже 1560 px, по бокам 80 px. Текст сверху начинается с 300 px.
- **Текст не заходит на предметы**, предметы не обрезаются краем, талисман не закрывает главное.
- **Чередуй фоны** каждые 1–2 сцены, но держи одну гамму. Тёмная/яркая сцена — как акцент, не чаще раза в 10 секунд (если весь ролик не в этой теме).
- Движение спокойное и дорогое: никакой тряски, мигания, резких склеек. Пружинка (`data-pop`) — только для иконок и плиток.
- Звуки тише голоса: pop/whoosh 0.08–0.14. Музыка ~0.065 (уже в render.mjs).
- **Чужие бренды:** логотипы и названия компаний — только если пользователь сам о них говорит. Свои персонажи и свои тексты, не копируй чужие ролики.
- Если пользователь даёт референс — бери из него приёмы (композиция, темп, цвет), не перерисовывай кадры один в один.

## Частые проблемы
- **Слово не появляется** — в `data-w` меньше чисел, чем слов. Посчитай слова (без `|`).
- **Текст раньше/позже голоса** — поправь число в `data-w` (время от начала сцены!).
- **Кадр пустой на секунде** — элемент ещё не появился (`data-in` больше) или сцена кончилась. Проверь `data-s/data-e`.
- **Иконка не видна** — нет файла в `a/icons/`, проверь имя.
- **Буквы другим шрифтом** — символа нет в Inter (редкие эмодзи в тексте). Убери или замени на `.ico`.
- **Рендер не запускается, «Не нашёл Google Chrome»** — установи Chrome (google.com/chrome).
