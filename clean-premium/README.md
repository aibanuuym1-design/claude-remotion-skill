# Чистый премиум — ролики без лица 9:16

Скилл для Claude Code: вертикальные ролики (Reels/Shorts/TikTok) без лица — голос за кадром + моушн-графика кодом.
Текст сверху появляется по словам ровно под голос, в центре телефон / ноутбук / стеклянные карточки / 3D-иконки, мягкие фоны, переходы через размытие, талисман.

Темы: светлая пастель (по умолчанию), `dark` (тёмная техно), `vivid` (яркая капсом).

Полные правила — [`SKILL.md`](SKILL.md), установка — [`КАК_УСТАНОВИТЬ.md`](КАК_УСТАНОВИТЬ.md).

## Как работает
1. Текст или готовая озвучка → `media/voice.mp3` + `media/words.json` (время каждого слова).
2. План сцен: одна фраза = одна сцена (1.3–4 с).
3. Сцены пишутся в `template/video.html` (`engine.js` и `style.css` не трогать).
4. `node render.mjs stills 1 4.5 …` — проверочные кадры; `node render.mjs full` → `out/video.mp4`.

Нужны Node.js 20+, ffmpeg, Google Chrome. Иконки — Microsoft Fluent Emoji 3D (MIT), шрифт Inter (OFL).
