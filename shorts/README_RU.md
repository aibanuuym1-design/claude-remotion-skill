# shorts — нарезка длинного видео в Shorts / Reels / TikTok

Скилл для Claude Code (оригинал — [claude-shorts](https://github.com/AgriciDaniel/claude-shorts), Agrici Daniel, лицензия MIT).
Берёт **длинное** видео (интервью, подкаст, лекция, запись экрана), находит самые сильные куски и делает из них
вертикальные ролики 1080×1920 с анимированными субтитрами по словам.

Английское описание — [`README.md`](README.md), инструкция для Claude — [`SKILL.md`](SKILL.md).

## Как попросить
> «Сделай шортсы из этого видео» · «нарежь рилсы» · «/shorts путь/к/видео.mp4»

## Что происходит (10 шагов)
1. **Проверка** — длительность, разрешение, есть ли звук, место на диске.
2. **Расшифровка** — faster-whisper, время каждого слова, язык определяется сам.
3. **Тип видео** — говорящая голова, запись экрана или подкаст.
4. **Анализ** — Claude читает расшифровку и оценивает 8–12 кусков по 15–55 с.
5. **Таблица кандидатов** — время, длина, балл, хук, почему работает.
6. **Ваш выбор** — какие куски, стиль субтитров, платформа; можно сдвинуть начало/конец.
7. **Точные границы** — резы по словам, концу фразы и паузам (не на полуслове).
8. **Подготовка** — вырезка кусков без перекодирования + расчёт кадрирования 9:16 по лицу (или по курсору).
9. **Рендер** — Remotion: субтитры, хук в первые 3,5 с, полоса прогресса.
10. **Экспорт** — файлы под YouTube Shorts / TikTok / Instagram Reels + проверка.

Claude ничего не рендерит без вашего подтверждения (шаг 6).

## Оценка кусков (0–100, порог 60)
| Критерий | Вес |
|---|---|
| Сила хука (первые секунды) | 0,30 |
| Понятен без остального видео | 0,25 |
| Эмоция | 0,20 |
| Польза на секунду | 0,15 |
| Концовка (вывод, панчлайн, призыв) | 0,10 |

## Стили субтитров
| Стиль | Шрифт | Вид | Для чего |
|---|---|---|---|
| **bold** | Montserrat Bold | КАПС, слово «выпрыгивает», активное слово жёлтое | бизнес, обучение, мотивация |
| **bounce** | Bangers | пружинит, яркие цвета | развлечения, реакции |
| **clean** | Inter Bold | мягкое появление, белый с тенью | интервью, спокойный тон |

⚠️ В шрифте Bangers **нет кириллицы** — для русской и казахской речи только `bold` или `clean`.

## Экспорт по платформам
| Платформа | Видео | Звук |
|---|---|---|
| YouTube Shorts | H.264 High 4.2, 12 Мбит/с | AAC 192k |
| TikTok | H.264, CRF 18 | AAC 128k |
| Instagram Reels | H.264 High 4.2, 4,5 Мбит/с (макс. 5) | AAC 128k |

Громкость везде выравнивается до −14 LUFS.

## Что нужно
FFmpeg, Python 3.10+ (`faster-whisper`, `mediapipe`, `opencv-python`, `numpy`), Node.js 18+ (`npm install` в `remotion/`).
GPU NVIDIA ускоряет расшифровку и экспорт, но всё работает и на процессоре.

## Структура
```
shorts/
```

## Заметки
- Эта копия настроена под **Windows** (PowerShell, `export.ps1`). В Linux/Mac команды те же по смыслу:
  Python из своего окружения, экспорт — теми же параметрами ffmpeg (см. `references/platform-specs.md`).
- Скилл для **длинных** видео. Если ролик короче ~2 минут, нарезать нечего — лучше смонтировать его целиком
  (например скиллом Nurserik Studio Hook или «Чистый премиум» из этого репозитория).
