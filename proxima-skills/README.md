# PROXIMA: скиллы для монтажа

Здесь 11 скиллов Claude Code для монтажа вертикальных и горизонтальных роликов кодом. Всё работает бесплатно, на своём компьютере. Источник: архив `PROXIMA-all-skills.zip` (https://proxima-montazh.pages.dev).

Каждая папка — отдельный скилл: `SKILL.md` (инструкция для Claude) плюс `template/` или `engine/` (код, шрифты, звуки). Почти во всех есть `КАК_УСТАНОВИТЬ.md`, инструкция для человека.

## Какой скилл выбрать

| Длинное видео (подкаст, стрим, лекция) | Несколько коротких клипов 9:16 | [shorts](shorts/SKILL.md) |

## Как скиллы связаны

```
сырое видео ──► clean-cut ──► cut.mp4 + subs.json ──┬─► expert-split
                                                     ├─► reels-motion-titles
                                                     └─► публикация как есть
длинное видео ──► shorts ──► клипы 9:16 с субтитрами
CapCut-проект (нарезан, покрашен) ──► capcut-effects
текст / голос ──► clean-premium | red-collage | paper-history
сценарий ──► cartoon-3d (короткая сценка) | cartoon-3d-short (история 1+ мин)
```

## Скиллы подробно

### 1. clean-cut — «Чистая нарезка»
- **Что делает:** вырезает паузы, «э-э», оговорки и дубли. Делает вертикаль 9:16 и анимированные субтитры по 1–2 слова с жёлтой плашкой на ключевом слове, плюс `.srt` для CapCut/Premiere.
- **Стек:** Python + sherpa-onnx (русский), faster-whisper (казахский и другие языки), ffmpeg, HTML-рендер субтитров в Chrome.
- **Шаги:** транскрипция → план «оставляю / вырезаю» (ждать «ок») → `cut.py --keep` → правка `subs.json` → кадры-проверка → `render_subs.mjs`.
- **Правила:** резать только одобренное; смысл не менять; субтитры дословно.
- **Когда срабатывает:** «вырежи паузы», «убери дубли», «джамп-каты», «черновой монтаж», «добавь субтитры».

### 2. shorts — длинное видео → шортсы
- **Что делает:** транскрибирует длинное видео (faster-whisper) и оценивает 8–12 кандидатов. Критерии: хук 0.30, самодостаточность 0.25, эмоции 0.20, плотность пользы 0.15, развязка 0.10. Даёт пользователю выбрать, прилепляет границы к паузам, кадрирует под 9:16 и рендерит субтитры в Remotion в стилях bold, bounce или clean. Экспорт под YouTube, TikTok и Instagram.
- **Источник:** claude-shorts, MIT, Daniel Agrici. Эта копия настроена под Windows (PowerShell, `export.ps1`).
- **Важно:** у стиля `bounce` шрифт Bangers без кириллицы, для русского только `bold` или `clean`. Нарезка через `-c copy`. Без одобрения сегментов ничего не рендерится.
- **Когда срабатывает:** «shorts», «нарежь клипы из видео», «tiktok/reels из видео».

### 3. reels-motion-titles — моушн-титры для говорящей головы
- **Что делает:** Remotion-ролик 9:16. Крупный узкий заголовок капсом, под ним неоновый рукописный курсив. Субтитры с жёлтой плашкой, стеклянные пилюли, карточки-скрины, стикеры, огромное слово **за** головой (вырезка человека), вспышки, стрелки CTA.
- **Стек:** Remotion (`src/core.tsx`: `Title`, `Script`, `Pill`, `Card`, `Sticker`, `Flash`, `Chevrons`), sherpa-onnx, YuNet-детектор лица, rembg.
- **Правила:** лицо никогда не закрывается, обязательная проверка `facecheck` перед отправкой. Безопасные зоны: 0–400 px сверху и 1560–1920 px снизу. Заголовок в одну строку из 2–4 слов. Цветовые пары `PAIRS` 1–7 чередуются. Зум не чаще раза в ~2.6 с.
- **Финал:** `loudnorm I=-14 TP=-1.5`.

### 4. expert-split — «Эксперт со схемой»
- **Что делает:** сверху по ходу речи собирается схема: неоновые карточки, «неправильно → правильно», буквы, цифры. Снизу спикер в скруглённой неоновой рамке. На эмоциях спикер на весь экран (`data-layout="full"`, не больше 1/3 ролика).
- **Зависимость:** сначала прогнать **clean-cut**, нужны `cut.mp4` и `subs.json`.
- **Особенности:** окно спикера задаётся `data-crop`. Темы `warm` (по умолчанию) и `dark`, акцент `--acc` берётся из фона спикера. Музыку можно сочинить кодом (`music.mjs warm|bright|soft`).
- **Правила:** схема строится под слова, на схеме коротко (слово, знак, цифра), 3–5 карточек максимум.

### 5. nurserik-studio-hook — «Nurserik Studio Hook»
- **Что делает:** таргет-креатив или рилс 9:16 с говорящей головой. Скилл из курса PROXIMA «Монтаж с Claude», модуль 11.
  - Над головой титры в два яруса: тонкая строка и крупное слово с хром-градиентом и лаймовой точкой. Плюс лаймовые наклонные плашки и пиксельное слово из мозаики.
  - Низ кадра под стеклянный чек-лист, три жирные строки и тёмные блоки с наклоном.
  - Полноэкранные цветные вставки: чёрная, розовая, синяя, белая с полем промпта, зелёная планета, тёмная со стрелкой-графиком. Ещё синий стеклянный телефон над головой и облачко мысли.
  - Финал всегда в двух вариантах: ссылка и «комментарийге Claude сөзін жаз». Отдельно делается ролик «ДО / ПОСЛЕ».
- **Языки:** казахский и русский.
- **Стек:** кадры видео + HTML-графика → Chrome → ffmpeg; MediaPipe (`selfie_segmenter.tflite`) для вырезки человека; faster-whisper.
- **Образцы:** `template/examples/` (kreativ1–3, do-posle).
- **13 правил Нұрсерік:**
  - текст никогда не на голове;
  - никакой «второй головы» сверху;
  - спикера не отдалять, зумов минимум;
  - низ кадра использовать под текст;
  - шрифты только Inter 800/400 (и курсив Lora);
  - вжухи только мягкие кинематографичные;
  - финал совпадает с голосом.

### 6. capcut-effects — «Эффекты для CapCut»
- **Что делает:** для готового (нарезанного и покрашенного) горизонтального видео 16:9 рисует эффекты в HTML и рендерит их прозрачными ProRes 4444. Потом сам вставляет их в `draft_content.json` проекта CapCut дорожками **над** корректирующими слоями, с бэкапом.
- **Элементы:**
  - текст справа белым и розовым (`#ff7eb6`) шрифтом Gotham;
  - графики, таблицы, окна-скрины с 3D-наклоном;
  - «20+» с сеткой переключателей iPhone, орбита Claude;
  - зачёркнутая сумма и линия по месяцам, поле ввода Claude.
- **Важно:** CapCut должен быть закрыт. Правка одного куска делается через `ONLY=… SUFFIX=_v2`, полная вставка заново сотрёт раскладку. Gotham и Helvetica не входят в скилл, если их нет, используются Montserrat и Inter.

### 7. clean-premium — «Чистый премиум»
- **Что делает:** ролик без лица 9:16, голос за кадром и спокойная «дорогая» моушн-графика.
  - Сверху текст по словам: тонкая строка и жирный акцент.
  - В кадре телефон, ноутбук, стеклянные карточки, 3D-иконки Fluent Emoji, кольца-выделения, счётчики.
  - Переходы через размытие, по кадру летает талисман.
- **Темы:** светлая (по умолчанию), `dark`, `vivid`.
- **Голос:** ElevenLabs API (`scripts/voice.mjs`, ключ в `.env`, в чат не выводить) или готовый mp3 + `words.py`.
- **Правила:** всё строго под голос; одна мысль — один предмет, не больше 3 иконок. Безопасные зоны: 220–1560 px по вертикали, 80 px по бокам. Звуки 0.08–0.14, музыка ~0.065.

### 8. red-collage — «Красный коллаж»
- **Что делает:** ролик-эссе без лица 9:16.
  - Тёмно-бордовый фон с зерном, вырезки в ч/б полутоне, текст капсом с засечками.
  - Красный пунктир по лицу, лицо пополам с черепом, лента-волна, счётчик лет.
  - Мел-обводки, флеш-нарезка, инверт и глитч, тоннель, удары-бумы, тёмный дрон.
- **Структура текста:** хук-парадокс в первую секунду, шок-картинка на 2–3 с, 6–9 фраз (20–35 с), перелом на 2/3, вывод, закольцованный с началом.
- **Темп:** смена картинки каждую ~1 с. Удар — раз в 2–4 с. Инверт или глитч и тоннель — по одному разу за ролик.
- **Цвет:** только бордовый, ч/б, кремовый текст и один красный акцент.
- **Инструменты:** `cut.py --mode dots|photo|clean` (rembg), звуки и дрон синтезированы кодом.

### 9. paper-history — «Бумажная история»
- **Что делает:** ролик 30–60 с в стиле бумажного коллажа. Архивные фото из Wikimedia Commons (только PD/CC0) с полутоном, рваная бумага, печати, карты (d3-geo), машинописные документы, стоп-моушн, шорох бумаги.
- **Источник:** движок papercut, MIT, Bashar Mokdad. Адаптирован под русский и казахский (`АВТОРСТВО.md`).
- **Сцены (`kind`):** `hero`, `photo`, `duo`, `number`, `document`, `timeline`, `quote`, `map`.
- **Правила:** каждый факт подтверждать двумя источниками; цитаты не выдумывать; не подписывать фото не тем предметом. Авторы фото пишутся в `CREDITS.txt`, их нужно вставить в описание ролика.
- **Установка:** `setup.sh` / `setup.ps1`.

### 10. cartoon-3d — «3D-мультик»
- **Что делает:** сценка 9:16 на Three.js. Герои из объёмных фигур в уютной комнате: рот двигается по голосу, герои моргают и меняют настроение. Камера переключается на того, кто говорит, внизу субтитры.
- **Герои по умолчанию:** `heroine` (девушка в розовом платке) и `cloudy` (Клоуди). Своих героев можно добавить в `heroes.js`.
- **Ввод:** `script.json` с полями `mode` day/night, `heroes`, `lines` (`who`, `audio`, `from`/`to`, `shot`, `mood`, `subs`).
- **Правила:** приметы героев не меняются; чужих персонажей не делать; не больше одной смены плана на реплику.

### 11. cartoon-3d-short — мультфильм-история в 3D
- **Что делает:** история на 55–70 с. Плоские 2D-герои с бобовыми головами и чернильным контуром в раскрашенном 3D-мире с чёрными линиями. Боке, плавные камеры, голос, синтезированные SFX и марш.
- **Стек:** three.js внутри Remotion. Проверено на «The Bridge That Fell for a Song».
- **Пайплайн:**
  1. Факты.
  2. Сценарий по формуле битов: хук → место → эскалация → слом → «Luckily / Unluckily» → объяснение через бытовую аналогию → следствие → поворот в конце.
  3. Голос и `words.json` (бесплатно через Kokoro: `voice_kokoro.py`).
  4. План кадров в `story.ts`.
  5. Мир, герои и пост-обработка.
  6. Звук (`templates/audio/`).
  7. Проверка картинки и QA (`short_qa.py`).
  8. Финал 1440×2560.
- **В `references/`:** готовые цифры стиля (свет, чернила, глубина, камера, персонажи) и метод «look-match» с песочницами и агентами-проверяющими.
- **Правила:** без надписей в кадре, английский, ровный тон голоса. Микс: музыка +3 дБ, SFX −6 дБ. Референс-материалы не публиковать, чужие сценарии и персонажей не копировать.
- **Перед стартом:** нужно создать Remotion-проект и скачать Kenney CC0 kit (см. Gotchas в SKILL.md).

## Общее для всех скиллов
- Пользователь обычно не программист: объяснять простыми словами, код не показывать, после каждого этапа говорить «что сделал» и «что проверить».
- Перед рендером всегда показывать план и кадры-проверку, дождаться «ок».
- Всё появляется ровно на слове, которое звучит.
- Безопасные зоны Reels: ничего важного у верхнего и нижнего края.
- Громкость под Reels: `loudnorm I=-14`.
- Распознавание путает имена, бренды и особенно казахский язык: спорные места уточнять у человека.
- Чужие ролики не копировать, брать только приём. Чужие бренды, лица и платные шрифты не публиковать.
- Нужно: Node.js 20+, ffmpeg, Google Chrome, Python 3.10–3.12 (точные пакеты указаны в каждом SKILL.md).

## Установка в Claude Code
Скопировать нужную папку в `~/.claude/skills/<имя>/` (для всех проектов) или в `.claude/skills/<имя>/` проекта. Либо перетащить исходный zip в Claude Code и написать: «Установи этот скилл для всех проектов».
