# Nurserik Studio Hook

> Скилл из обучения **Нұрсерік** — курс **PROXIMA «Монтаж с Claude»**, модуль 11 «Кейс: таргет-креативы».
> Нұрсерік собрал его на своих трёх таргет-креативах и ролике «до/после»: каждое правило ниже — его реальная правка.
> Нұрсеріктің оқуындағы скилл: Нұрсерік өз креативтерін дәл осылай монтаждады.

Показывая план или результат, говори «по скиллу Nurserik Studio Hook» / «как в креативах Нұрсерік».

Ролик 9:16 из сырого видео с говорящей головой. Всё делается кодом: кадры видео + HTML-графика → Chrome рисует каждый кадр → ffmpeg собирает с голосом и звуками. CapCut не нужен.

Пользователь — не программист. Объясняй просто, код не показывай без просьбы. После каждого этапа: «что сделал» и «что проверить». Пользователь хочет быть «выше всех» — дешёвые шаблонные элементы не принимает.

Образцы (принятые финалы) — в `template/examples/`:
- `kreativ1.html` — креатив 1 (37 с): хук над головой, розовая вставка с окном YouTube, тёмные карточки, белая вставка с полем ввода, синяя со счётчиком, зелёная воронка, ДО/ПОСЛЕ в телефонах, розовый/салатовый финал.
- `kreativ2.html` — креатив 2 v5 (40 с): чек-лист внизу, три жирные строки внизу, 4 примера на «осындай», синий телефон над головой, планета с карточками, красная стрелка, облачко мысли.
- `kreativ3.html` — креатив 3 v3 (47 с): список цен внизу со счётчиками, примеры в телефонах, синий телефон, белая вставка «видео/промпт/скилл», тёмные блоки «бот/сайт/платформа» внизу.
- `do-posle.html` — ролик ДО / ПОСЛЕ (сырой исходник слева, готовый справа).
Проекты на диске: `Desktop\CLAUDE скиллы\рилс идеи\креатив-таргет-1 / -2 / -3 / -3-до-после`.

## Первый запуск
1. Скопируй `template/` в новую папку проекта (`рилс идеи/креатив-таргет-N/`).
2. Нужны Node.js 20+, ffmpeg, Google Chrome, Python 3.10–3.12 с `faster-whisper numpy opencv-python mediapipe`.
3. `npm install` (или junction на `node_modules` соседнего проекта: `mklink /J node_modules ..\креатив-таргет-1\node_modules`).
4. Модель вырезки человека — `template/models/selfie_segmenter.tflite`.

## Как монтировать (по шагам)
1. **Кадры и звук.** `ffmpeg -i ИСХОДНИК -vf fps=30 -q:v 3 media/frames/%05d.jpg` (если не 1080×1920 — добавь `scale=1080:1920`), `ffmpeg -i ИСХОДНИК -vn -c:a aac -b:a 192k media/voice.m4a`. Число кадров → `data-frames`, длина → `data-dur`.
2. **Речь.** `python -I scripts/words.py ИСХОДНИК kk > media/words.json`. Речь казахская с русскими словами — ставь `kk`. Если выдаёт бред («Субтитры сделал…», «бұл үшін» по кругу) — не тот язык или длинный кусок: режь на 10–12 с, пробуй `ru`. Смысл сверяй сам, тайминги бери из файла. Сомнительные слова/цифры назови пользователю в конце.
3. **Маски.** `python scripts/mask.py` → `media/mask/*.png`. Замерь верх головы по маскам (по всему ролику) — от этого зависит `data-ty`.
4. **План.** Сцены по 2–4 с = одна мысль. Чередуй 2–3 сцены «спикер + титры» и 1 полноэкранную вставку. Покажи пользователю план одной таблицей и сразу делай (он не любит ждать).
5. **Код** в `video.html` (бери ближайший образец из `examples/`). `engine.js`/`style.css` не трогай без нужды.
6. **Кадры-проверка.** `node render.mjs stills 2.2 4.2 …` — по кадру в каждой сцене, склей в лист, посмотри сам. Проверь чек-лист ниже.
7. **Рендер.** `node render.mjs full` (47 с ≈ 7–8 мин). Если оборвался — `$env:RESUME="1"; node render.mjs full` продолжит с места.
8. **Два варианта финала** — всегда: со ссылкой (как говорит голос) и «комментарийге Claude сөзін жаз». Держи `video-link.html` и `video-comment.html`, рендери подряд.
9. **Музыка** (по просьбе) — тайп-бит на фоне, см. ниже.
10. Готовые файлы копируй на рабочий стол с понятным именем; финалы пользователь переносит в `Videos\креатив\ГОТОВЫЙ`.

## Как устроен video.html
```html
<body data-frames="1366" data-dur="47.00" data-ty="300" data-intro="zoom">
<section class="scene" data-s="0" data-e="2.45" data-cam="1" data-cy="30">
  <div class="small cx" style="top:236px" data-in="0" data-fx="words" data-w="0 0.42">енді бір</div>
  <div class="big cx bh" style="top:282px" data-in="0.64" data-fx="squash" data-sfx="thud" data-vol="0.2">экспертный<span class="dot">.</span></div>
</section>
<section class="scene full bg-pink" data-s="14.70" data-e="16.48">…</section>
```
- Сцена: `data-s/data-e` — секунды ролика. **Все времена элементов — от начала сцены.**
- `data-ty` — на сколько опустить спикера, чтобы над головой была полоса под титры (обычно 300). `data-cam="1"` всегда (без приближений). `data-push` по умолчанию 0.015.
- `<body data-intro="zoom">` — мягкий наезд в начале без размытия; `data-intro="none"` — вообще без эффекта (для ДО/ПОСЛЕ).
- `data-fx`: `blur` (из размытия, с `data-from` + `data-dist` — плавно всплывает), `squash` (удар крупного слова), `pop`, `slide`, `words` + `data-w`, `type` (печать), `scramble`, `jelly`, `none`. Уход: `data-out` + `data-outfx`.
- `bh` — элемент за вырезанным человеком.
- `img.seq data-seq="папка/" data-f0 data-nf [data-loop] [data-sin]` — живое видео в окне/телефоне.
- `data-count="0 150000" data-cdur data-post=" ₸"` — счётчик. `data-strike` — зачёркивание. `data-press` — нажатие кнопки. `data-turn` — поворот стрелки (`.abox`). `data-tr="none"` — склейка без размытия.
- Звуки: `data-sfx="pop|whoosh|thud|click|glitch|tick|boom"`, `data-vol`. Переходы между сценами — сами, мягкие `cin1..3`.

## Правила Нұрсерік (каждое — его реальная правка на креативах)
1. **Текст и графика никогда не заходят на голову и лицо.** Титры — в полосе 220–520 px над головой. Если не влезает — уменьшай текст, а не налезай. Плашки сбоку — только вне головы, проверяй на кадрах в моменты, когда спикер двигается.
2. **Никакой «второй головы».** Верх кадра при `data-ty` заполняет `#ext` — только растянутая полоса стены над головой (scaleY ~3.2, blur 14px). Никогда не размытая копия всего кадра — в ней видна голова над настоящей.
3. **Не отдалять спикера** с растворёнными краями — виден шов. Масштаб кадра = 1.
4. **Зумы по минимуму**: без приближений (cam 1.12+), без punch. Начало — мягкий наезд без размытия (размытие в начале «некрасиво»).
5. **Используй низ кадра** под текст и блоки (грудь/стол) — «снизу ничего нет, используй низ».
6. **Строки плотно, но без касаний** — хвосты «у», «р», «д» не трогают соседнюю строку; две строки заголовка близко.
7. **Шрифты**: Inter 800 (жирный хром) + Inter 400 (тонкий). Лаймовый курсив Lora — допустим как в креативе 1. Неон, моно-шрифты, засечки, «третий шрифт» — нет.
8. **Перечисления — не стеклянные карточки вокруг головы** («дёшево, как у всех»), а тёмные блоки с наклоном или стеклянный список внизу.
9. **Всё появляется ровно на своём слове**, плавно (снизу из размытия), без резких вылетов. Каждый пример работ — на своём «осындай».
10. **Звуки**: переходы — мягкие кинематографичные вжухи (`cin1..3` из «Саунд Пак» пользователя), тише голоса. Резкие вжухи — нет.
11. **Не нравится и не делать**: неон-моушн на весь экран, мемы со знаменитостями (и риск для рекламы), таймер-секундомер, синий узкий капс «туториал», кнопки с курсором, рамы на стене как основной приём, слишком мелкие плашки.
12. **Финал по голосу**: говорит «сілтеме» → кнопка-ссылка; второй вариант всегда «комментарийге Claude сөзін жаз».
13. **Сомнительное распознавание** (цифры, сленг) — назови пользователю, не выдумывай.

## Музыка (тайп-бит)
Пользователь просит «чуть-чуть рэп, инструментал, на фоне, гармонично». Бит подмешивается к готовому mp4 без перерендера, с приглушением под голос:
```
ffmpeg -i ГОТОВЫЙ.mp4 -ss 5.9 -i БИТ.mp3 -filter_complex "[1:a]atrim=0:ДЛИНА,asetpts=PTS-STARTPTS,volume=0.32,afade=t=in:d=0.4,afade=t=out:st=ДЛИНА-1.6:d=1.6[mu];[0:a]asplit=2[main][sc];[mu][sc]sidechaincompress=threshold=0.02:ratio=5:attack=15:release=350[md];[main][md]amix=inputs=2:normalize=0:duration=first,loudnorm=I=-14:TP=-1.5[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k "… + музыка.mp4"
```
Цель — бит примерно на 14 дБ тише голоса (замерь). `-ss` — пропусти тихое вступление трека. Предупреди про лицензию: трек из платной библиотеки в рекламе требует лицензии.

## ДО / ПОСЛЕ (examples/do-posle.html)
Тёмный фон с сеткой, сверху две жирные строки («монтажға қолымның / ұшын да тигізбедім.»), слева маленький наклонённый телефон «ДЕЙІН» с **сырым исходником**, справа большой «КЕЙІН» с готовым роликом, стрелка между ними, снизу тонкая строка + лаймовая кнопка **ровно по центру** (`.ctab.cx`). Звук — **только из готового** (с музыкой, если есть). Без эффектов появления: `data-intro="none"`, все `data-in="0"`, `data-fx="none"`. Два варианта — кнопка «сілтемені бас» и «комментарийге «Claude» сөзін жаз»; во втором в «КЕЙІН» ставь креатив с финалом-комментарием.

## Чек-лист перед рендером
- [ ] Над головой нет второго силуэта; текст не на голове ни в одном кадре сцены.
- [ ] Ничего важного выше 220 px и ниже 1560 px.
- [ ] Нет касаний букв между строками; заголовки не вылезают за края.
- [ ] Каждый элемент — на своём слове; примеры — плавно снизу.
- [ ] Финал совпадает с голосом; есть второй вариант.

## Частые проблемы
- **Рендер завис / оборвался** — `RESUME=1` продолжает с места. Не запускай два рендера в одной папке одновременно.
- **Правка через PowerShell не применилась** — кириллица в командной строке ломается; правь `video.html` инструментом Edit/Write.
- **Элемент не виден в кадре 0** — у него `data-in > 0` или `data-fx` по умолчанию `blur`; для статики ставь `data-in="0" data-fx="none"`.
- **Человек дёргается по краю** — перезапусти `mask.py`. **MediaPipe не видит модель** — путь с кириллицей (скрипт читает модель в память).
